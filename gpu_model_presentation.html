Layer 1 — Price Dynamics

価格関数 P(t)

P(t) = P₀ × (1 - δ(t))ᵗ × DS(t)

各変数の意味

P₀ = 47.5万円/月 HIGH

GMO公開料金（専有380万/8GPU）から直接取得

δ(t) = 年間価格下落率 MED

初期30%→定常5%へロジスティック減速。
H100実績（$9→$2, R²=0.978）で校正

DS(t) = 需給バランス比 LOW

(1+g_d)ᵗ / (1+g_s)ᵗ
需要25% vs 供給35%。直接データなし

A100: $48/TFLOP → H100: $30 → B200: $11/TFLOP。

Derivation — g_d 需要成長率

g_d の推定: 4つの方法で 25-40%/年

推定方法と根拠データ

方法1: 市場調査レポートCAGR MED

8社のGPUaaS市場予測（2024-2030）:
Grand View 21.6% / MarketsandMarkets 26.5% / Mordor 28.7% / Fortune BI 35.8%。
中央値 ~27-29%（長期平滑化）

方法2: Hyperscaler CAPEX実績 HIGH

AWS+MS+Google+Meta+Oracle AI投資:
2022: $150B → 2024: $256B → 2025: $443B → 2026E: $602-690B。CAGR ~53%

方法3: NVIDIA DC売上 HIGH

FY22 $10.6B → FY26 $193.7B（4年CAGR 107%）。
GPU単価上昇(20-30%/年)を除く実質 = ~60-80%。
直近FY26は +68% YoY

方法4: AI訓練計算量 MED

フロンティアモデル計算量 年4-5倍増加。
HW効率改善(~3x/年)を差引くと実質 30-70%。
推論需要の急成長も追加要因

注意: 近年(2024-26)は55-70%と高いが、中期(2027-)は35-50%に減速、長期は25-30%に収束する見通し。現行モデルの25%は長期値としては妥当だが、近年を過小評価。

Derivation — g_s 供給成長率

g_s の推定: 4つの方法で 35-65%/年

推定方法と根拠データ

方法1: NVIDIA GPU出荷数 HIGH

みずほ推計: 2023年 376万基 → 2025年E 650-700万基。
ユニットCAGR = 34%。設置ベースは退役考慮で~41%成長

方法2: DC容量+CoWoS拡張 MED

TSMC CoWoSウェハ: 2024 37万枚 → 2026E 100万枚 (CAGR 64%)。300社超のGPU Cloud新規参入。日本: 政府補助金7,250億円

方法3: 価格下落からの逆推定 LOW

H100レンタル 76%下落(33ヶ月)。需要25%成長を仮定し需給均衡から逆算 → g_s = 65-75%（初期は希少性解消を含み過大）

方法4: NVIDIA売上÷ASP分解 MED

DC売上 $15B→$194B、推定ASP $4K→$22.5K。
数量成長 ~41%。AMD+TPU+Trainium込みで 45-55%

注意: 物理ユニット(35-45%)とクラウド利用可能容量(40-65%)と価格含意供給(50-100%)で異なる。モデルでは物理ベースの35%を採用するのが安全だが、neocloudブームが続けば実効供給はこれを上回る。

Layer 1 — Utilization

稼働率関数 U(t)

U(t) = R(t) × U₀ × C(t) × D(t)

4つの構成要素

R(t) ランプアップ MED

S字カーブ。GMO実績: 9ヶ月で月次黒字化

U₀ 初期稼働率 = 75% MED

GMO月次黒字化→50%超は確実。業界平均15-30%との乖離大

C(t) 競合圧力 LOW

max(1 - α×N_new, 0.5)。α=0.015はモデル固有。実績校正なし

D(t) 需要ブースト LOW

clip(DS(t), 0.7, 1.15)。需給比から派生

07 / 19
Derivation — U₀ 初期稼働率

U₀ の推定: 3つの方法で 75% に収束

推定方法と根拠データ

方法1: 公開企業の開示 HIGH

CoreWeave S-1: バックログ$15.1B/4年、25万GPU → 配分稼働率 80-90%（長期契約型）
Lambda Labs: ~80%でビジネスモデル構築
Aethir報告: 業界平均 15-30%（計算利用率。レンタル稼働率とは異なる）

方法2: GMO損益分岐逆算 MED

純CAPEX 80.7億、年間償却16.1億+OPEX 8.6億 → BEP稼働率 ~59%
9ヶ月で月次黒字化 → 59%超は確定。
Turing契約(32億/4年)で ~18% は確保済 → 残り41%を市場で獲得

方法3: 業界調査・ベンチマーク MED

LBNL (2024): DC平均 ~50%
GPU訓練時: 80-93% / 推論時: 40-60%
混合ワークロード: 60-80%
DC業界BEP閾値: 60-70%

結論: 損益分岐(59%) < U₀ < CoreWeave(85%)。GMO長期契約実績+黒字化実績から 75% が妥当な中央値。悲観60% / 楽観85%で感度分析。

構造的課題: 高稼働率の源泉である長期契約は30-50%割引を伴う。本モデルはU₀=75%とP₀=47.5万を独立に仮定しているが、実際にはトレードオフ関係。

Derivation — α 競合感度

α の推定: 3つの方法で 0.015-0.020

推定方法と根拠データ

方法1: クラウドIaaS先例 MED

AWS IaaSシェア: 2-3年で~10pp低下、6件の競争イベント。
1件あたり ~1.7pp のシェア喪失。
市場成長(22% CAGR)調整後の稼働率影響 = 1.0-2.0%
CDN業界: マージン7pp低下/5年 → 弱者淘汰パターン確認

方法2: さくら下方修正分析 MED

GPU Cloud売上: 158億 → 85億（46%減）
要因分解: 競合 ~50%、大口契約喪失 ~50%
競合分を3社の新規参入で割ると = 7-8%/社（売上）
価格低下分を除く稼働率影響 = 3-5%/社

方法3: クールノー競争理論 MED

対称N社クールノー均衡: 1社増 → 各社シェア 1/[N(N+1)] 減
N=8: 1.4pp低下（シェアの11.1%）
供給超過(g_s-g_d=10%)調整後 = 1.0-2.5%

結論: α = 0.015 は3手法すべてのレンジ内。保守推奨値は 0.020。
国内GPU Cloud参入: GMO, さくら, KDDI, SB, NTTPC, ハイレゾ, ルチラ + Hyperscaler 4社 = 計11社

注意: Hyperscaler 1社(AWS値下げ)のインパクト > 独立系10社。この異質性は線形αでは捕捉できない。閾値効果の可能性もあり。

Reliability Assessment

このモデルで言えること・言えないこと

言えること

  • GPU価格は年15-30%下落が続く
    R²=0.978、11点の実績データで検証
  • 費用構造は固定費支配（80%超）
    CoreWeave S-1と構造的に一致
  • 稼働率が損益を決定的に左右する
    損益分岐稼働率 ~85%（Y1）
  • ベースケースでは投資回収困難
    NPV -98.5億円（中央値パラメータ）
  • 最大リスクは需給バランスとSWコスト
    感度分析で定量的に確認

言えないこと

  • ⚠ 投資回収の「正確な確率」
    9.3%は条件付き推定。真の確率ではない
  • ⚠ 5年後以降の市場構造
    次世代GPU、量子計算等の構造変化は含まない
  • ⚠ 不連続イベントの影響
    大口解約、NVIDIA政策転換、規制変更
  • ⚠ パラメータ間の相関構造
    独立サンプリングで過度に分散する
  • ⚠ 数式モデル自体の妥当性
    DS(t)やα等の関数形は仮説にすぎない

Summary

モデルの結論

GPU Cloud事業は構造的に固定費が重く、 価格下落と競合激化の中で持続的な黒字化が困難な事業モデル。 ただし楽観シナリオでは高リターンの可能性も存在する。
